## s3lim inventory setup

Configure S3 inventory delivery on one or more S3 source buckets

### Synopsis

Configure S3 inventory delivery on multiple S3 buckets to deliver daily/weekly reports
to a central inventory destination bucket for processing with s3lim Standard or Read-Only.

```
s3lim inventory setup [flags]
```

```
  -b, --buckets strings      Comma-separated list of source bucket names to configure
  -d, --destination string   Target S3 destination URI (e.g. s3://central-inventory-bucket/inventory/)
  -f, --format string        Inventory output format (Parquet, CSV, ORC) (default "Parquet")
      --frequency string     Inventory report frequency (Daily or Weekly) (default "Daily")
  -h, --help                 help for setup
```
